## 🧩 Featured Projects

### 🌾 AgriCore Operation Platform  
*C# • .NET Framework • SQL Server • Windows Forms*

A comprehensive farm management solution designed to streamline agricultural operations for small to medium‑scale farmers.

- **Secure Authentication** – User login with salted password hashing (AES‑256 encryption).
- **Crop & Field Management** – Maintain farmer‑specific crop records and field plots.
- **Smart Scheduling** – Automated irrigation and fertilizer reminders based on crop type and growth stage.
- **Pest & Disease Tracker** – Log and monitor infestations with treatment recommendations.
- **Market & Sales Module** – Record harvest yields, sales transactions, and generate profit summaries.
- **Role‑Based Access** – Separate dashboards for farm owners and field workers.

> *Built as a semester project, demonstrating full‑stack desktop application architecture and database integration.*
